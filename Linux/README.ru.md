# GunLast r4: установка на Fedora Linux через Steam/Proton

**Статус: предварительная поддержка Proton, игровой запуск пока не проверен.**
Это Linux-установщик и замена Windows batch-launcher. Это не нативный порт
Outlast и не полный архив мода: два бинарных пакета в GitHub отсутствуют.

## Что потребуется

- Fedora Linux на x86_64, Steam, Python **3.11 или новее** (`python3 --version`).
  При отсутствии Python: `sudo dnf install python3`. Сам установщик запускайте без sudo.
- Лицензионный Outlast (Steam AppID **238320**), **Windows Win64 depot**.
- Распакованная папка **Files** оригинального дистрибутива **M9-r4** со всеми
  семью файлами `Custom/OutlastPistolMod/...` из `manifest.json`.
  Страница автора: https://www.nexusmods.com/outlast/mods/143.
  Номер публичного релиза может отличаться: определяющими являются SHA-256.
  Если архив недоступен, запросите его у автора: установщик не обходит карантин
  и не скачивает пакеты автоматически.

В свойствах Outlast в Steam откройте «Совместимость» и принудительно выберите
Proton от Valve. Дождитесь обновления игры. Проверьте обычный запуск через Steam,
выберите 64-битный вариант при запросе и закройте игру и launcher.
Точная рабочая версия Proton для GunLast пока не установлена; установленный
на машине разработки Proton 11.0 не проходил игровой тест этого мода.

## Проверка и установка

В терминале перейдите в корень распакованного репозитория GunLast:

```sh
python3 Linux/gunlast.py doctor
python3 Linux/gunlast.py doctor --payload '/путь/к/архиву/Files'
python3 Linux/gunlast.py install --payload '/путь/к/архиву/Files'
```

Путь к игре определяется по `appmanifest_238320.acf` и `libraryfolders.vdf`,
включая дополнительные библиотеки и типичное расположение Flatpak Steam.
Если найдено несколько установок или нестандартное расположение:

```sh
python3 Linux/gunlast.py install --game '/mnt/games/SteamLibrary/steamapps/common/Outlast' --payload '/путь/к/Files'
```

Установщик выводит **готовую строку параметров запуска Steam**, например:

```sh
python3 '/mnt/games/SteamLibrary/steamapps/common/Outlast/.gunlast/gunlast.py' run --game '/mnt/games/SteamLibrary/steamapps/common/Outlast' -- %command%
```

Скопируйте выведенную строку в «Свойства → Общие → Параметры запуска» Outlast.
Запускайте игру кнопкой Steam. Не подставляйте `wine` вместо `%command%`:
Steam выбирает Proton, среду исполнения и prefix. Wrapper меняет только
исполняемый файл на `Binaries/Win64/OLGame.exe`, оставляя команду Proton.
Добавляются оригинальные параметры `-NoSteam -NOHOMEDIR -log`.
`-NoSteam` сохранён для соответствия оригинальному launcher; достижения,
Steam Cloud и прочая интеграция Steam этим способом не гарантируются.

При Flatpak Steam путь к скрипту и `python3` должны быть видны внутри среды,
из которой Steam запускает `%command%`. Этот вариант **не тестировался**.
Обнаружение Flatpak-библиотеки само по себе не подтверждает запуск wrapper.
Если среда не видит Python или внешний диск, используйте обычную установку
Steam либо настройте доступ к библиотеке через штатные средства Flatpak.
Отключать SELinux не требуется. NTFS/exFAT и библиотеки с симлинками в целевых
путях не тестировались; установка намеренно отказывается от таких симлинков.

## Фактическое устройство и пути

Мод — восемь классов UnrealScript, скомпилированных в Unreal package `.u`
и переименованных без преобразования в `.OLScript`. Отдельных DLL/EXE мода нет.
`M9Assets.OLContent` содержит обязательные меши и звук; исходники не позволяют
его восстановить. Один лишь `RuntimeConfig` не делает мод работоспособным.

| Назначение | Путь от корня Outlast |
| --- | --- |
| Windows-игра | `Binaries/Win64/OLGame.exe` |
| Пакеты и настройки мода | `Custom/OutlastPistolMod/Content` и `Config` |
| Подключённые пакеты | `OLGame/CookedPCConsole/Custom/Campaign/*.OLScript`, `*.OLContent` |
| Временная конфигурация | `OLGame/Config/DefaultEngine.ini`, `DefaultGame.ini`, `DefaultInput.ini` |
| Журнал и исходные файлы | `.gunlast/state.json`, `.gunlast/backup` |
| Снимок конфигурации сеанса | `.gunlast/session.json`, `.gunlast/session-backup` |

Оригинальный `.bat` создаёт junction `Campaign` и использует robocopy.
Linux-версия копирует два пакета в этот каталог, проверяя конфликты,
и восстанавливает временную конфигурацию после завершения игры.
Пакеты остаются подключёнными до удаления мода. Для чистого обычного запуска
рекомендуется удалить мод, а не только очистить параметры Steam.

Снимок включает весь `OLGame/Config`, в том числе генерируемые `OL*.ini`.
При запуске такие `.ini` временно удаляются, чтобы настройки класса игры и
клавиш не перекрывались старым кэшем UE3; при выходе исходные файлы возвращаются,
а новые файлы конфигурации удаляются. Изменения настроек во время мод-сеанса
не сохраняются. Не редактируйте конфиги и не обновляйте игру во время сеанса.

`DefaultGame.ini` выбирает `OutlastPistolMod.PistolGame` и
`OutlastPistolMod.PistolPlayerController`. Saves установщик не копирует;
с `-NOHOMEDIR` движок может писать сохранения/логи в дерево установки.
Перед игровым тестом самостоятельно сохраните копию `OLGame/SaveData`,
`OLGame/Save`, если они существуют, и своих обычных сохранений.
Штатный Proton prefix: `<SteamLibrary>/steamapps/compatdata/238320/pfx`.
При обычном запуске без `-NOHOMEDIR` пользовательские данные могут находиться
в Documents внутри prefix; этот установщик их не изменяет.

## Восстановление и удаление

Закройте игру. После сбоя питания/SIGKILL или предупреждения о незавершённом сеансе:

```sh
python3 Linux/gunlast.py recover --game '/путь/к/Outlast'
```

При установленном моде это восстанавливает конфиги, сохраняя установку мода.
При прерванной установке — отменяет её по журналу. Не удаляйте `.gunlast`
вручную до восстановления: там единственная копия заменённых файлов.
При обычном завершении и ненулевом коде выхода восстановление автоматическое.
Если процесс игры пережил wrapper, снимок остаётся для ручного восстановления.

Для удаления:

```sh
python3 Linux/gunlast.py uninstall --game '/путь/к/Outlast'
```

После удаления очистите параметры запуска в Steam. Если установленный файл
изменился, удаление откажется его затирать: сохраните свою копию и верните
исходный файл из r4, затем повторите. Не запускайте одновременно другие моды.
Пустые созданные каталоги удаляются по возможности; `.gunlast.lock` может
оставаться как безвредный файл блокировки.

## Проверено и что остаётся проверить

30 октября 2026: Fedora 44, Python 3.14.8. Автотесты используют искусственный
payload с отдельными тестовыми хешами и подставной процесс Proton, **не игру**.
Проверены установка/удаление/повторная установка, откат при ошибке копирования,
старые дубликаты пакета, несовпадение хешей, конфликты, симлинки, блокировка,
восстановление после сеанса и обнаружение дополнительной Steam-библиотеки.
Рабочий manifest тестами не ослабляется и должен совпадать с Windows r4.

На машине обнаружена реальная игра по пути
`/mnt/games/SteamLibrary/steamapps/common/Outlast`, но с
`Binaries/Linux/OLGame.x86_64`, без Win64 EXE. `doctor` корректно отказал в
установке. Игра и её настройки не изменены.

Нет оригинальных `M9Assets.OLContent` и `OutlastPistolMod.OLScript`.
Поэтому **совместимость пакетов с Proton, загрузка PistolGame, отображение M9,
стрельба, перезарядка, подбор магазинов, сохранения и полный игровой проход
не подтверждены**. Уже в исходном r4 подбор магазинов отмечен как непроверенный.
Нативный Linux Outlast этим установщиком не поддерживается: совместимость
его Unreal-пакетов/ABI не установлена. Сборка UDK под Wine не выполнялась;
штатные требования сборки остаются в `BUILD_INSTRUCTIONS.md`.

Перед стабильным релизом нужны: оба r4 пакета с ожидаемыми хешами; запуск
Win64 Outlast через Proton; проверка PistolGame/M9 в логе; игровые проверки
выше; проверка восстановления после выхода и аварии; отдельный Flatpak-тест.
`-log` включает лог движка, а `PROTON_LOG=1` перед строкой параметров Steam —
диагностику Proton (обычно `~/steam-238320.log`).

## Тесты и архив инструментов

```sh
python3 -m unittest discover -s Linux/tests -v
python3 Linux/package.py --output /tmp/gunlast-linux-tools.tar.gz
```

Архив содержит инструменты, manifest и документацию, **без бинарного payload**.
Он не обозначается полноценным игровым релизом. Права на сторонние ассеты
не установлены — см. `REVIEW_NOTES.md`. Исходный `SOURCE_SHA256.json` относится
к первоначальным review-материалам, не к новым Linux-файлам/изменённому README.

Источники: `DistributionScripts/Install.ps1`, `Level_Launcher.bat`,
`manifest.json`, `RuntimeConfig`, `BUILD_INSTRUCTIONS.md`, `REVIEW_NOTES.md`;
[Valve Proton](https://github.com/ValveSoftware/Proton),
[SDK](https://github.com/superboo07/Outlast-Level-Editor).
